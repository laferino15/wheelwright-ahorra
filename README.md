
# Wheelwright Ahorra

Marketplace local multi-comercio para Wheelwright, Santa Fe.

## Objetivo

Centralizar las compras de diferentes comercios de Wheelwright
en una única plataforma digital, con carrito unificado,
gestión de pedidos y delivery a domicilio.

## Tecnología

- Odoo 19 Community
- Python
- PostgreSQL
- XML
- JavaScript
- Git / GitHub

## Comercios iniciales

1. Carnicería
2. Panadería
3. Farmacia
4. Ferretería
5. Huerta Express

## Funcionalidades principales

- Catálogo multi-comercio.
- Categorías y productos.
- Carrito único.
- Checkout.
- Gestión de pedidos.
- Preparación por comercio.
- Logística y delivery.
- Pago al recibir.
- Comisiones por comercio.
- Reportes de gestión.

## Estructura

- `addons/custom`: módulos personalizados de Odoo.
- `docs`: documentación funcional y técnica.
- `scripts`: herramientas de desarrollo.
- `tests`: pruebas automatizadas.

## Entornos

- Desarrollo: local.
- Producción: pedidosya.asartorio.online.

## Reglas de trabajo

- No almacenar credenciales en Git.
- No subir bases de datos de producción.
- No modificar producción durante el desarrollo.
- Validar cada funcionalidad antes de desplegar.
- Trabajar mediante ramas y pull requests.
